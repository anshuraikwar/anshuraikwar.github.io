## Development

### Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio locally.

### Build

```bash
pnpm build
```

### Start

```bash
pnpm start
```

## Deployment

This site is ready for deployment on platforms that support Next.js, such as Vercel.

For more information on Next.js deployment, visit: https://nextjs.org/docs/deployment
